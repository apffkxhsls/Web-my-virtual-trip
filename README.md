# 🌿 My Virtual Trip
### 마이 버추얼 트립

> 취향에 맞는 여행지 탐색부터 숙박·항공 정보 확인, 여행 계획과 기록까지 한곳에서 관리하는 통합 여행 서비스.

<br>

## ✈️ 프로젝트 소개

여행을 준비할 때 여행지, 숙박, 항공, 일정을 서로 다른 서비스에서
찾아야 하는 번거로움을 줄이고자 기획했습니다.

<br>

## 👥 팀원 소개

| 이름 | 역할 | 담당 페이지 |
| :---: | :---: | --- |
| 김예지 | 팀장 | 숙박 · 항공 |
| 김지호 | 팀원 | 테마별 탐색 · 여행 계획 |
| 박지현 | 팀원 | 여행지 상세 정보 · 여행 기록 |
| 심현희 | 팀원 | 메인 · 지역별 탐색 |

<br>

## 🧭 페이지 구성

| 페이지 | 주요 내용 |
| --- | --- |
| 🏠 메인 | 여행지 검색 UI, 추천 여행지·테마·숙소 |
| 🎞️ 테마별 탐색 | 여행 테마별 추천 여행지, 앵커 링크 이동 |
| 🗺️ 지역별 탐색 | 대륙·국가 선택 UI, 추천 도시, 축제·행사 |
| 📍 여행지 상세 | 교토 소개, 관광 명소, 맛집·카페 |
| 📝 여행 계획 | 여행 기본 정보, 날짜별 일정·메모, 예상 지출 |
| 📔 여행 기록 | 개인 여행 기록 카드, 여행 사진 모음 |
| 🏨 숙박 | 숙박 검색 UI, 필터·정렬 UI, 숙소 카드 |
| 🎫 항공 | 항공 검색 UI, 필터, 티켓형 카드, 안내·영상 |

<br>

## 🛠️ 사용 기술

- **HTML5** — 페이지 구조 및 입력 요소 구성
- **CSS3** — 레이아웃, 색상, 카드 및 상호작용 스타일
- **Git · GitHub** — 버전 관리, 이슈 및 PR을 통한 협업
- **Google Fonts** — Asta Sans 웹 폰트
