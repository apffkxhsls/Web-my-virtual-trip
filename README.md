# 🌿 My Virtual Trip
### 마이 버추얼 트립

취향에 맞는 여행지 탐색부터 숙박·항공 정보 확인, 여행 계획과 기록까지 한곳에서 관리하는 여행 웹사이트입니다.

## 프로젝트 소개

여행을 준비할 때 여행지, 숙박, 항공, 일정을 여러 서비스에서 찾아야 하는 번거로움을 줄이고자 기획했습니다.

지역과 테마에 따라 여행지를 탐색하고, 숙박·항공 정보를 비교하며 여행 계획과 기록을 작성할 수 있습니다.

## 팀원 소개

| 이름 | 역할 | 담당 |
| :---: | :---: | --- |
| 김예지 | 팀장 | 숙박·항공 목록 및 상세 페이지 |
| 김지호 | 팀원 | 테마별 탐색·여행 계획·마이페이지 |
| 박지현 | 팀원 | 여행지 상세·여행 기록 |
| 심현희 | 팀원 | 메인·지역별 탐색·검색 결과 |

## 주요 기능

| 페이지 | 구현 기능 |
| --- | --- |
| 메인 | 추천 여행지 캐러셀, 인기 테마·숙소 표시, 여행지 검색, 찜 |
| 지역별 탐색 | 대륙·국가 선택, 인기·추천 도시 더보기·접기, 축제·행사 정보, 도시 찜 |
| 테마별 탐색 | 테마 선택에 따른 여행지 표시, 자동 배너 전환, 여행지 찜 |
| 검색 결과 | 지역·테마·축제 개최 월에 따른 여행지 검색, 재검색, 여행지 찜 |
| 여행지 상세 | 교토·상하이·부산 소개, 명소 상세 모달, 사진 확대·갤러리, 명소 찜, 지도 연결 |
| 숙박 | 지역·인원 검색, 날짜 입력 검증, 숙소 유형·가격 필터, 가격·평점 정렬, 숙소 찜 |
| 숙소 상세 | 선택한 숙소의 정보·소개·요금 표시, 숙소 찜, 공식 예약 사이트 연결 |
| 항공 | 출발지·도착지·날짜 검색, 직항·경유 및 항공사 필터, 정렬, 왕복·편도와 인원에 따른 금액 계산 |
| 항공 상세 | 가는 편·오는 편 일정, 예상 총액 표시, 항공사 공식 사이트 연결 |
| 여행 계획 | 기본 정보·날짜별 일정 작성, 예산·지출 계산, 체크리스트, 저장·불러오기·삭제 |
| 여행 기록 | 일차별 방문 장소·날씨·기분·일기 작성, 사진 선택, 지출 기록, 조회·수정·삭제, 사진 슬라이드쇼 |
| 마이페이지 | 찜한 여행지·명소·숙소 조회 및 취소, 저장한 여행 계획·기록 확인 |

## 사용 기술

- **HTML5**: 페이지 구조, 폼 및 입력 요소 구성
- **CSS3**: Flexbox 레이아웃, 카드 디자인, hover 효과 및 전환 효과
- **JavaScript**: 이벤트 처리, DOM 조작, 검색·필터·정렬 및 화면 갱신
- **Fetch API·JSON**: 로컬 JSON 데이터를 비동기로 불러와 화면에 표시
- **LocalStorage**: 찜 목록, 여행 계획 및 여행 기록 저장
- **SessionStorage**: 선택한 항목과 검색 조건을 페이지 간 전달
- **Git·GitHub**: 브랜치, 커밋 및 Pull Request를 통한 협업

## 실행 방법

1. 저장소를 다운로드하거나 복제합니다.
2. VS Code에서 프로젝트 폴더를 엽니다.
3. Live Server 확장 프로그램을 실행합니다.
4. 다음 파일을 시작 페이지로 엽니다.

   `src/html/12_웹벤져스_main.html`

JSON 데이터를 Fetch로 불러오므로 HTML 파일을 직접 여는 대신 Live Server 등의 로컬 웹 서버를 사용해주세요.

## 폴더 구조

    Web-my-virtual-trip/
    ├── src/
    │   ├── html/       # 페이지 구조
    │   ├── css/        # 공통 및 페이지별 스타일
    │   ├── js/         # 페이지별 기능과 데이터 처리
    │   ├── data/       # 여행지·숙소·항공·계획·기록 JSON
    │   └── res/
    │       ├── icons/  # 아이콘
    │       └── images/ # 이미지
    └── README.md

## 이용 안내

- 별도의 서버와 데이터베이스 없이 로컬 JSON과 브라우저 저장소를 사용합니다.
- 저장한 정보는 같은 브라우저와 사이트 주소에서 유지되며, 브라우저 데이터를 삭제하면 사라질 수 있습니다.
- 숙소 요금과 항공편 정보는 기능 구현을 위한 예시 데이터입니다. 실제 운항 일정·예약 가능 여부·요금은 연결된 공식 사이트에서 확인해주세요.
- 여행 기록의 사진은 프로젝트에 포함된 이미지 목록에서 선택합니다.
